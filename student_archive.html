数据与备份

班级名单优先从原教师发布台 homework-hub 自动读取。旧 Excel 每个工作表只有学生姓名和课次记录、没有班级字段，因此系统会用教师端名单按姓名自动匹配班级；未匹配的学生会显示在“未设置班级”中。导入 Excel 不会修改原文件。
GitHub 私有仓库设置

学员姓名、课次和完成情况只写入私有仓库。令牌仅保存在浏览器，不要写进 HTML 或公开分享。与教师发布台相同浏览器、相同网址下可复用已保存的 gh_token。

需要先创建一个 GitHub 私有仓库。令牌建议仅授权所需仓库的 Contents 读写权限。若仓库未配置，页面仍可本地工作，但无法保证跨设备同步。
