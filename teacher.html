GitHub 发布与档案同步设置（首次使用配置）

学生端作业放在现有 homework-hub 仓库。学员档案必须放在独立的私有仓库中，不能将学生姓名、课次与完成情况写入公开仓库。令牌只保存在当前浏览器中，不要分享或写进 HTML 文件。

同一 GitHub 令牌需要同时具备 homework-hub 的 Contents 读写权限，以及私有学员档案仓库的 Contents 读写权限。档案仓库尚未配置时，作业仍可发布，但不会自动同步进个人档案。
